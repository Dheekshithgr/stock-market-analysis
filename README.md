Stock Market Analysis System

Overview
This project analyzes stock market data using technical indicators like:
- Moving Averages (MA50, MA200)
- RSI (Relative Strength Index)
- MACD (Moving Average Convergence Divergence)

It generates BUY / SELL / HOLD signals and visualizes them using matplotlib.

---

 Features
- Fetches real stock data using yfinance
- Calculates multiple technical indicators
- Generates trading signals
- Visualizes price trends with BUY/SELL markers
- Provides today's trading suggestion

---

Example Output
- Price chart with signals
- RSI and MACD analysis
- Live BUY/SELL suggestion

---

Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- yfinance
